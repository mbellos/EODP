# EODP
## Repository Structure & Version Control

To facilitate development tracking and project traceability, this repository is organized into the following branches:

* **Session Branches:** A dedicated branch is provided for each session, labeled by date, documenting the step-by-step code evolution and updates through incremental commit histories.
* **`Final-Submission` Branch:** Serves as the main branch and final release of the project. It contains the complete integration of all pipeline modules (ISM, L1B, L1C, and E2E) with fully tested, end-to-end functional code.
